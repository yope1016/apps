プライバシーポリシー

制定日：2026年10月31日

本ポリシーは、「小さな便利ツール集」（https://yope1016.github.io/apps/、以下「本サイト」）と、運営者が自身のYouTubeチャンネルへ動画をアップロードするために使う社内ツール「hq uploader」（以下「本ツール」）に適用されます。

1. 本サイトで取得する情報

本サイトのツールは、入力された内容をサーバーへ送信しません。処理はすべてお使いのブラウザ内で完結します。アクセス状況の把握のため、Cloudflare Web Analytics を利用しています。Cookieを使わず、個人を特定する情報は収集しません（Cloudflareのプライバシーポリシー：https://www.cloudflare.com/privacypolicy/）。

2. 本ツール（hq uploader）について

本ツールは YouTube API Services を利用し、運営者自身が管理するYouTubeチャンネルに、運営者が制作した動画をアップロードする目的でのみ使用します。第三者のGoogleアカウントやYouTubeデータへのアクセス、取得、保存、共有は行いません。要求する権限は動画のアップロード（youtube.upload）のみです。認証情報は暗号化された保管領域に保存し、運営者以外は利用できません。

本ツールの利用には、YouTube利用規約（https://www.youtube.com/t/terms）およびGoogleプライバシーポリシー（https://policies.google.com/privacy）が適用されます。Googleのセキュリティ設定ページ（https://security.google.com/settings/security/permissions）から、いつでもアクセス権を取り消せます。

3. 第三者提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。

4. お問い合わせ

本ポリシーに関するお問い合わせは、https://github.com/yope1016/apps/issues までお寄せください。

Privacy Policy
